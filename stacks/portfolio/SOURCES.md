# Sources and interpretation

Reviewed October 20, 2026. These references support the technical topics. Lesson order, sample sizes, time budgets, and pass thresholds are custom portfolio recommendations, not requirements issued by these organizations.

| Source | How it is used |
| --- | --- |
| [NIST NICE framework introduction](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/getting-started) | Organize learning around demonstrated tasks, knowledge, and skills |
| [OpenSSH manuals](https://www.openssh.org/manual.html) | Client/server identity, authentication, configuration, and forwarding |
| [Ruff tutorial](https://docs.astral.sh/ruff/tutorial/) | Python linting, formatting, and reviewed fixes |
| [OWASP WSTG v4.2](https://owasp.org/www-project-web-security-testing-guide/v42/) | Versioned web-security assessment methodology |
| [OWASP Juice Shop](https://owasp.org/projects/juice-shop) | Intentionally vulnerable training target |
| [CREST penetration testing guide](https://www.crest-approved.org/wp-content/uploads/2023/04/A-Guide-to-Penetration-Testing-2022.pdf) | Scoping, findings, reporting, remediation, and retest expectations |
| [MITRE ATT&CK](https://attack.mitre.org/) | Vocabulary for observed adversary behavior and defense discussion |
| [Espressif build/flash/monitor](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/start-project.html) | Separate source build, flashing, and runtime observation |
| [Espressif IDE workshop](https://developer.espressif.com/workshops/esp-idf-setup/) | Supported VS Code/ESP-IDF workflow when appropriate for the selected board project |
| [Ollama FAQ](https://docs.ollama.com/faq) | Local runtime configuration, cloud disabling, resource/context settings, and inspection |
| [OWASP prompt injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) | Agent tests involving untrusted content and tool boundaries |
