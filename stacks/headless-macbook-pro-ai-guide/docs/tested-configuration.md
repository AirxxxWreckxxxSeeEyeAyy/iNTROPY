# Beta test record

Recorded October 20, 2026. This is a report of observed behavior, not a guarantee for every Mac.

## Reference setup

- Server: Apple M1 MacBook Pro, 8 GB RAM, macOS 14.8.7.
- Client: MacBook Air, using SSH and Terminal.
- Ollama 0.40.5; Open WebUI 0.12.3; Python 3.11.11.
- Local-only services on ports 11434 and 8080.
- Installed: Gemma 3 4B, Llama 3.2 3B, and an older Gemma 2 model. The older model is not recommended by this guide.

The display test kept one SSH connection alive for 90 seconds. Connecting AC power briefly woke the display during that period. Logs established approximately 46 seconds of display-off operation at the end, with SSH heartbeats continuing. This is not a claim of 90 uninterrupted dark seconds or of system-sleep persistence.

The original private setup used its own helpers and service names. This repository generalizes that setup into `org.headlessmac` services and new helper files. Passing tests on generated files does not equal a complete deployment test. Run the documented acceptance checks before relying on unattended operation.

## Reproduce the repository checks

From the guide folder:

```sh
python3 -m unittest discover -s tests -v
bash -n scripts/pro-chat
bash -n scripts/pro-webui
```

Record new hardware/software results in a pull request, keeping personal hostnames, keys, and conversations private.
