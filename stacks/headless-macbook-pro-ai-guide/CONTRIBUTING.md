# Contributing

This is a beta. Small corrections and clearly reported hardware tests are welcome.

Issues belong in the parent iNTROPY repository; pull requests should affect this guide folder. Keep hostnames, keys, passwords, chat data, prompts, and personal documents out of public reports.

Keep commands clearly labeled **Air** or **Pro**. Link technical claims to official sources. Mark untested procedures honestly. Do not bundle model weights or private chat databases. Run the checks in [the test record](docs/tested-configuration.md) for script changes. Contributions to this guide and its scripts are provided under its MIT license.
